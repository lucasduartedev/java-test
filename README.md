# 🧪 Prática de Testes Unitários em Java com JUnit

## 📌 Sobre o projeto
Este repositório foi criado **exclusivamente para estudo e prática de testes unitários em Java**.  
Aqui aplico conceitos fundamentais e intermediários de **JUnit**, organização de testes, boas práticas e validação de lógica de programação.

O projeto é composto por **mini projetos independentes**, cada um focado em um problema específico, permitindo:
- Evolução incremental do conhecimento em testes
- Experimentação sem impacto em projetos reais
- Exploração de cenários comuns cobrados em entrevistas e no dia a dia profissional

## 🎯 Objetivos principais
- Consolidar o uso de testes unitários em Java  
- Praticar TDD (Test-Driven Development) quando aplicável  
- Testar regras de negócio, validações e fluxos lógicos  
- Melhorar legibilidade, manutenção e confiabilidade do código  

## 🛠️ Tecnologias utilizadas
- **Java 17**
- **Spring Boot**
- **JUnit 5**
- **Maven**

## 📂 Estrutura do repositório
- Cada pacote representa um mini projeto ou cenário de teste
- Código simples, focado em lógica e clareza
- Testes organizados seguindo boas práticas de nomenclatura

## ⚠️ Observação
Este repositório **não tem finalidade de produção**.
Seu uso é estritamente educacional, experimental e voltado para aprendizado contínuo.
